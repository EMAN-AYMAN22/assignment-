4. WhatistheDifferenceBetweentheCallStack,EventQueue,andEventLoopinNode.js?
-Call Stack: Executes code synchronously using LIFO
-Event Queue (Callback registration): Stores completed asynchronous callbacks using FIFO
-Event Loop: The continuously running process that checks the Call Stack. If the Call Stack is empty,
 it grabs the first task from the Event Queue and pushes it onto the Call Stack to run.
